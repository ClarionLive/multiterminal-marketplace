# Project Proposal Display Format

Use this format for both Create New (Step 5) and Add Existing (Step E5).

```
PROJECT PROPOSAL
Name:         [PROJECT_NAME]
Description:  [PROJECT_DESCRIPTION]
Type:         [ARCHETYPE] ([project_type])
Path:         [PROJECT_PATH]
Source:       [SOURCE_PATH — only show if different from Path]

Build:        [build_command]
Output:       [build_output_path]
Deploy:       [deploy_path]
Launch:       [launch_command]

Agents:       [agent list]
MCPs:         [global MCPs always included] + [optional_mcps list, or "none"]

Git:          [Init new repo / Already has .git / remote URL / Skip]
.gitignore:   [template name]
Git branch:   [branch name, default: main]
Auto-commit:  [yes/no]
```

Note: Skills and specialist agents are auto-configured after project creation and are not shown here.
